# Origami Benchmark — public source snapshot

图解驱动的交互式折纸 benchmark 研究原型。包含模拟器控制接口、模型策略、不可撤销的尝试日志与预算机制、通用评分程序、查看器源码，以及开发阶段的公开图解。

## 发布范围

按项目所有者要求，本仓库不包含参考动作、目标状态、评分数据、评测输出、交接文档、API 密钥和第三方书页。通用评分程序不包含题目的私有答案。原始完整项目保留在本地。

**这是公开代码快照，不是开箱即用的完整评测包。** 缺少私有任务资产和轨迹时，评测、参考执行及查看器中的历史结果功能无法完整运行。物理仿真还需要独立安装原生后端。公开图解属于开发校准数据，不应当作独立泛化测试集。数据中的历史难度标签尚未完成校准。

## 目录

- `origami_bench/`：控制器、模型接口、尝试日志、通用评测逻辑。
- `data/*/public/`：公开任务描述和原创图解；外部来源仅保留链接。
- `viewer/benchmark/`：查看器及其依赖许可。
- `requirements*.txt`：Python 依赖记录；原生物理后端不在其中。

## 已知限制

薄壳后端与几何后端必须区分；未知碰撞或应变有效性不等于通过。部分高级操作尚不支持。现有源码与历史冻结版本有差异，本次发布不宣称复现历史分数，也不发布未经验收的百题评测。

未运行新的模型调用或付费实验。第三方组件保留原有许可，本仓库没有额外授予第三方素材的再分发权。
