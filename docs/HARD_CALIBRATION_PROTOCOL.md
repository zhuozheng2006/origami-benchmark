# Pre-registered hard-task calibration

The first cohort uses every newly qualified real-source precrease task, H102 and H103, with the existing three provider-declared models: GPT-6 Astra, Claude Opus 5.5 and Gemini 4 Argon. Names are requested/returned API declarations, not independent attestation of model weights.

Before any paid call, generic observation defects were repaired: expanded paper viewports preserve physical board ticks and keep rectangular/translated paper visible; a uniform v16 policy gives explicit task scope precedence over default printed order and discloses the existing 600-frame rotation limit. Actions, solver, material and scoring thresholds remain unchanged. The old public-v4-precrease1 tag and its reference evidence remain intact.

Each run has 40 total attempts, an 8192-token response cap, no measurement tools, no automatic API or episode retry, the same complete public attempt history, and private goals excluded. Requests and all failures are retained. Each independent run has a fresh UUID and explicit repeat ID.

The first batch has six episodes. If it suggests low success, confirm with a second separately registered batch of all six combinations rather than selecting only failed cases. The operational target is pooled success at most 1/3, each model at most 1/2, at least four valid completed episodes per model and two independent source tasks. These small-sample results are descriptive; they are not a guaranteed ceiling or an unbiased held-out leaderboard.

Every failure is inspected against the source, instructions and supported controller. Environment errors, ambiguous source annotations, returned-model discrepancies and unsupported valid equivalent actions cannot establish model incapability. Report operational outcomes separately from audited model errors. A task change requires a new frozen cohort; old results are never overwritten or pooled as if the protocol had not changed.

The shared cumulative budget remains CNY 150 with CNY 140 operating guard. This study family has a shared CNY 40 stage cap across batches; prior unknown reservations remain intact. A low score is never a reason to bypass a budget stop. If this cohort is solved reliably, qualify the next multi-layer/spatial cohort with full physical positive references and real negative controls before evaluating it.
