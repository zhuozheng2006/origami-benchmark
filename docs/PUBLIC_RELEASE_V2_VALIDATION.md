## 评分边界

逐步裁图、整页读图、多层中间态分轨报告，development/test 分开，参考动作和诊断题不计作模型成绩。批量入口保留非零退出和日志，启动失败也有环境错误报告，不能悄悄从分母移除。

本版仍是固定网格、理想夹持、未实物标定材料下的 scoped 物理验收。未知物理有效性不能通过。O04 和 U 系列的姿态/顺序评分歧义仍列为诊断；未支持沉折或任意复杂现代折法不能因此声称已解决。历史模型分数不自动成为本版本的模型成绩。

分类页的题号搜索、状态筛选、题目范围与参考链接已在浏览器检查；L01 的 3D 回放已实际跳至第 2577 帧并核对折叠终态。10 项公开测试通过，包括 135 份证据重评分、冻结数据与资产检查、预算不可撤销、批量启动失败保留、分轨/分割汇总。

证据重评分相信输入记录，不是防作弊验证。真正测试新 Agent 应通过 evaluate_public.py / run_suite.py 新建运行目录，使用自己的模型，保留所有尝试。
